# 2주차

## 서버 운영 방법
- 베어메탈
    - PC 한대에에 여러 OS를 설치후 여러 소프트웨어 운영함.
- 하이퍼바이저
    - 전통적 가상화 기술
    - 호스트 OS 리소스를 사용하여 게스트 OS를 실행.
    - 게스트 OS에 리소스 할당 (CPU, Memory, Disk, Network ...)
    - 프로그램 → 시스템 콜 → 게스트OS 커널 → 가상 하드웨어 → 하이퍼바이저 → 실제 하드웨어
- 컨테이너
    - 하이퍼바이저보다 가볍고 빠름
    - 호스트 OS 커널 기능으로 **격리된 공간** 을 만들 수 있음
    - 핵심기술
        - namespace : 프로세스, 파일시스템, 네트워크 등의 격리
        - cgroups : 리소스 사용량 제어
