## 쉘 스크립트 中 쓸모없는 출력 처리 방법
```
$ >/dev/null 2>&1 

# >/dev/null 
# > 는 표준출력 1이 생략된 표현.
# 표준출력을 /dev/null 이라는 미리 합의된 쓰레기통으로 보내라는 의미.
# 표준출력 필요없다는것임.
# 2>&1 
# 에러또한 1번, 표준출력이 바라보는 쓰레기통에 연결하겠다.
# 표준출력, 표준에러 다 안보겠다!

```


## 쉘 스크립트 中 heredoc 해석방법 스위치

```
$ MODEL="qwen3"
$ cat > test.sh << 'END' # << 'END', "END", \END 모두 같은의미
> echo "$MODEL"
> END

$ cat test.sh
echo "$MODEL"

# 본문에서 등장하는 표현식을 지금 해석할것인지 결정하는 문법임.
# 따옴표(위에서 등장하는 세가지 표현방법을 모두 통칭한다.)로 END(반드시 END일 필요 없음. 보통 EOF를 많이 사용.)를 감싸면 지금 해석하지 말아라. 나중에 해석하겠다.
# 따옴표로 END를 감싸지 않으면 지금 해석하라.
```
